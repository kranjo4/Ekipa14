# Frontend

React frontend za aplikacijo Ekipa 14. Omogoča prijavo, upravljanje uporabnikov, telesnih mer in treningov.

## Zagon

Iz te mape zaženi:

```powershell
npm install
npm start
```

Aplikacija je nato dostopna na `http://localhost:3000`. Backend mora hkrati teči na `http://localhost:8080`.

## Ukazi

```powershell
npm start       # razvojni strežnik
npm test        # testi
npm run build   # produkcijski build
```

Celoten opis projekta, nastavitev MySQL in zagona je v [README.md](../../README.md).
